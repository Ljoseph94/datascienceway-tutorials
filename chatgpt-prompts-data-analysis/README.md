# How to Use ChatGPT for Data Analysis (Safely and Effectively)

Code for the DataScienceWay tutorial: **[How to Use ChatGPT for Data Analysis (Safely and Effectively)](https://datascienceway.com/chatgpt-prompts-data-analysis/)**

- `tutorial.py` — all Python examples from the post, in order (run: `python tutorial.py`)
