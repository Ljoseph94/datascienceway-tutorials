# SQL Joins Explained: INNER, LEFT, and the Mistakes Everyone Makes

Code for the DataScienceWay tutorial: **[SQL Joins Explained: INNER, LEFT, and the Mistakes Everyone Makes](https://datascienceway.com/sql-joins-explained/)**

## Files

- `schema.sql` — creates the sample tables
- `queries.sql` — every query from the post
- `run_queries.py` — loads schema.sql into in-memory SQLite and runs each query (run: `python run_queries.py`)

No external data needed: sample data is created by the code or included here.
