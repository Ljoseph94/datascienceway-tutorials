# DataScienceWay Tutorials

Runnable code from the tutorials on **[DataScienceWay](https://datascienceway.com)** — practical data science, Python, SQL, Excel, machine learning and AI how-tos.

Each folder matches one published tutorial and contains the code from the post (Python scripts, SQL files or Excel workbooks), small sample data where needed, and a README linking back to the article. New folders are added as new tutorials go live.

## Getting started

```bash
git clone https://github.com/Ljoseph94/datascienceway-tutorials.git
cd datascienceway-tutorials
pip install -r requirements.txt
python pandas-read-csv-guide/tutorial.py          # Python tutorials
python sql-joins-explained/run_queries.py          # SQL tutorials (SQLite, built into Python)
```

Tested with Python 3.10+, pandas 2.x and scikit-learn 1.x.
